替换风险

single Slot 通常已有官方组件。注册会替换原区域，并可能连带移除它声明的子 Slot。尤其不要注册 root；全局浮层应使用 shell.overlay。

统计依据：当前项目安装的 @deepseek-ai/dsh-client-* 0.1.0-rc.6 类型声明。红框是可视区域归类，不代表只有 11 个 Slot；多个细粒度 Slot 会共享同一个屏幕区域。
